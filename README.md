# GLOAMDEEP — Delve the Nine Vaults

A roguelite dungeon crawler. Three heroes descend nine procedurally generated
vaults across three realms, and the Hollow King waits at the bottom. Every run
earns shards for a permanent skill tree — die, return, descend stronger.

- **3 heroes, 3 ways to fight** — Vanguard (sword arcs + shield bash), Embermage (exploding fireballs + ember nova), Thornbow (fast arrows + thorn volley). Dash with i-frames, potions, and a special on every class.
- **9 vaults, 3 realms** — Sunken Halls, Ember Warrens, Gloom Throne. Every vault is a new dungeon: 12 rooms joined by a spanning tree, with combat, treasure, elite and throne rooms, pillars, hazards, and chests.
- **12 enemy kinds + 3 bosses** — chasers, drifters, swarmers, spitters, armored beetles, chargers, splitters, imps, drakes, frost wights, cultists, shades, brutes — and the Tide Warden, Ember Matriarch, and the two-phase Hollow King.
- **Layered progression** — XP and level-ups with a choice of 3 boons; loot with 4 rarities across weapon, armor, and trinket slots; 8 relics that change the build; a shop between vaults; and a meta skill tree bought with shards that persist across runs.
- **Dense HUD** — HP/XP bars, gold, shards, kills, timer, objective tracker, live minimap, equipment slots, relics, and ability cooldowns — plus a boss bar on throne fights.
- **Full shell** — title with class select and skill tree, pause, level-up choices, shop, victory and defeat screens with full run statistics, localStorage save, WebAudio synth sound and ambient pad.
